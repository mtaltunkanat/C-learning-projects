## Hakkında

Bu repository, **C programlama dilini öğrenme sürecimi** belgelemek için oluşturuldu.

Temel programlama kavramlarından başlayarak algoritma geliştirme, problem çözme ve daha ileri C konularına doğru ilerliyorum.

Amacım yalnızca kod yazmayı öğrenmek değil, kodun nasıl çalıştığını anlamak ve öğrendiklerimi gerçek projelerle pekiştirmek.

## İlk C Programım

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

### Programı derlemek ve çalıştırmak

GCC kullanarak:

```bash
gcc main.c -o main.exe
```

Windows terminalinde çalıştırmak için:

```powershell
.\main.exe
```
